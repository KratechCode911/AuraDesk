# AURA

AURA es una aplicación de fondos de pantalla animados para Windows de 64 bits. Esta beta incluye el fondo web Órbita y el motor multimedia libVLC.

## Descargar y abrir AURA

1. Abre **Releases** en este repositorio y selecciona la beta para Windows.
2. En **Assets**, descarga `AURA.zip`.
3. Haz clic derecho sobre el ZIP y selecciona **Extraer todo**.
4. Abre la carpeta `AURA` y ejecuta `AuraDesk.exe`. Conserva las DLL y las subcarpetas junto al ejecutable.

## Informar de un problema

Abre una incidencia en **Issues**. Indica tu versión de Windows, el tipo de fondo, el número de monitores y los pasos que permiten repetir el fallo. Si afecta al rendimiento, incluye el modelo de tu gráfica.

Los créditos y el aviso de licencia de libVLC se encuentran en `libvlc/win-x64/AUTHORS.txt` y `libvlc/win-x64/COPYING.txt` dentro de la descarga.
